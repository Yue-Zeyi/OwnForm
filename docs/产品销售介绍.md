# OwnForm — 开源自托管表单收集与私域引流系统

**一套可以商业使用的表单收集 + 内容页面 + 引流获客系统源码。** 部署在自己的服务器上，数据 100% 自己掌控。无需续费、无数量限制、无品牌水印——源码在手，想怎么用就怎么用。

---

## 它解决什么问题

你可能正在为这些问题付费或烦恼：

- 用在线表单 SaaS，每月交订阅费，数据存在别人服务器，导出受限，想定制没门
- 用普通活码工具，群码满了手动换图、客服码轮着发，全靠人工盯
- 微信群二维码 7 天过期、满员作废，印在物料上的码天天作废重印
- 客户要"部署到我们自己服务器"的项目，找不到能交付的自有产品

**OwnForm 给你的答案：一次部署，无限使用，私有部署，源码交付——表单收集、内容页面、活码引流一站搞定。**

## 功能总览

### 📋 表单收集（核心）

- **拖拽式设计器**：文本、下拉、单选复选、日期、数字、评分、级联（含省市区三级联动）、图片/文件上传等控件，必填与正则校验可视化配置
- **发布即收集**：一键发布生成分享链接与二维码，手机电脑均可填写
- **防刷验证全套**：图形验证码、短信验证码（阿里云/腾讯云）、极验滑块、访问密码、限一次提交、提交频率限制、蜜罐反机器人——按表单自由组合
- **数据管理**：列表/详情/搜索筛选/时间排序、旗标标记、备注、回收站、跨表单聚合视图、一键导出 CSV（支持敏感字段脱敏）
- **批量操作**：多选批量删除/标旗/备注/审核，效率翻倍
- **审核模式**：提交先审后显，垃圾信息不污染数据
- **统计分析**：每个表单独立统计页——提交趋势图、设备占比、选择题分布、高频答案排行
- **渠道协作**：分发渠道码归属到成员，配合定时上下线精准投放；成员数据范围逐表单授权
- **新提交通知**：钉钉、企业微信、飞书机器人或自定义 Webhook，邮件通知、每日汇总亦可

### 📄 自定义页面（内容承载）

不止收集表单，还能发布内容：

- 自带 **wangEditor 富文本编辑器**与 HTML 源码模式
- **页面里直接内嵌表单**——写一篇活动介绍，表单就嵌在文章中间，访客看完即填，转化率远高于"阅读原文"跳转
- 页面之间、页面与表单之间自由互相引用
- 多套展示模板 + 主题色自定义，适配不同场景审美
- 支持 SEO 标题/关键词/描述设置与访问密码
- 提交成功后自动跳转指定页面，闭环承接

### 🔗 引流中心（活码 + 短链，私域获客利器）

对标商业引流工具的核心能力，二维码长期不变、内容随时可换：

**活码系统——群满自动换群**
- 一个二维码印在物料上长期使用，扫码后落地页自动分发二维码图片
- 每张图可设**扫码上限**：第 1 群满 200 人自动切到第 2 群，无需人工盯群换图
- 分发方式：**顺序轮询 / 随机分配 / 并流多码齐推**（多群同时推，访客任选识别）
- 落地页手机优先、官方风格卡片，标题与「长按识别二维码」引导语可自定义
- 全部满员自动展示自定义提示（如"请联系客服加入新群"）
- **长按识别次数统计**——比扫码量更接近真实转化

**短链——多域名轮询防封**
- 长链接一键转短链，点击统计齐全
- 一个短码背后配多条目标链接**轮询跳转**（多域名轮换，单域名被限制也不影响）
- 可选**中转引导页**：微信/抖音内提示「右上角浏览器打开」，规避封闭环境拦截

**精准分流——每张码/每条链接三重规则**
- **权重**：2:1 配比意味着第一个目标获得约三分之二流量
- **设备**：iOS / 安卓 / 电脑分开导流（如安卓导下载页、iOS 导 App Store）
- **时段**：按小时窗口生效，支持跨零点（白天导客服 A、夜间导客服 B）
- 规则不命中的访客自动落到其他目标，绝不落空

**域名池**：系统可绑定多个域名，表单/页面/活码/短链的分享链接可指定使用落地域名或备用域名——一个域名出问题，全站链接一键切换。

### 🛡️ 数据与合规（0.0.3 新增）

- **数据保留策略**：提交数据按保留天数自动清理（含回收站），满足个人信息最小化留存要求
- **手动清理**：过期提交 / 回收站 / 孤儿附件独立勾选、天数自定义，二次确认后执行，全程留操作日志
- **每日汇总邮件**：每天自动把昨日数据概要发到指定邮箱
- 敏感字段（手机号/身份证）导出可选自动脱敏

### 🤖 AI 助理（增值能力）

接入任意 OpenAI 兼容大模型（DeepSeek、通义千问、智谱、Kimi 等均可）：

- 对话式生成表单："帮我做一个经销商签约信息收集"→ 秒出完整表单
- 对话式生成页面内容："写一份春招宣讲会页面，带报名表单"→ 直接产出可用内容
- 模型与密钥自主可控，密钥加密存储、后端代理调用、不暴露到浏览器

### 📊 数据概览

登录即见全局：提交量四维卡片（总量/本月/近 7 日/今日，均带环比）、资源统计（表单/页面/引流/附件）、热门表单与页面/推广位排行、最新提交实时滚动。

### 🏢 多用户与权限

- 管理员 + 普通成员两种角色
- 成员之间数据完全隔离（表单、页面、推广位、统计全部服务端强制隔离）
- 管理员可创建/禁用成员、设置成员功能权限、查看全员统计、审计全部操作日志
- 适合团队共用，也适合"你运营平台、客户注册使用"的轻 SaaS 模式

### 🎨 自由白标

系统名称、Logo、登录页文案、页脚版权、备案号全部后台可改——**去掉 OwnForm 的名字，它就是你的产品**。

## 技术亮点（给技术决策者）

| 维度 | 说明 |
|---|---|
| 架构 | ThinkPHP 8 + Vue 3 + Element Plus，前后端分离，主流技术栈好招人好维护 |
| 访客端 | 零框架依赖的原生轻量实现（非 SPA），首屏快、SEO 友好、低配服务器无压力 |
| 数据安全 | 表单/短信/邮件/AI 密钥 AES-256-GCM 加密落库，后台仅显示掩码，数据库拖走也拿不到明文 |
| 防攻击 | CSRF Token 全覆盖、XSS 双重消毒（22 组攻击向量实测拦截）、SQL 全参数化、SSRF 出站白名单、验证码防爆破、登录防撞库、会话固定防护 |
| 越权防护 | 成员数据强制服务端隔离（非前端摆设），每个接口逐一审计过 |
| 上传安全 | 类型白名单 + 文件内容校验 + 配额限制，防木马防穿越 |
| 质量保障 | 经多轮全方位安全审计与功能自检，引流分发逻辑经加权轮询/设备/时段/跨零点/满员切换全场景实测 |
