# OwnForm 系统介绍

自托管的开源表单收集与私域引流系统：通过可视化设计器搭建表单收集数据，搭配可自定义的内容页面发布活动信息，再借助活码与短链把各渠道流量精准导入私域。数据完全存储在自己的服务器，不依赖任何第三方 SaaS。

- 技术栈：ThinkPHP 8（后端）+ Vue 3 / Element Plus / wangEditor v5 / form-create（管理端）+ 原生 Vue 3 UMD（访客端，轻量免构建）
- 部署形态：宝塔 / Nginx / Apache 均可，PHP ≥ 8.0，MySQL 5.7 / 8.0
- 当前版本：**0.0.3**

---

## 核心能力

### 表单（核心模块）

- **可视化设计器**：拖拽搭建，支持输入框、下拉、单复选、日期、评分、级联、省市区三级联动、图片/文件上传等控件，必填与正则校验，字段可配 Element Plus 图标与说明文字，提交按钮位置可自由摆放
- **多种防刷验证**：图形验证码（5 位、失败即作废、按 IP 限频）、短信验证码（阿里云/腾讯云）、极验 v4，可组合访问密码、提交限频、限一次提交、蜜罐字段
- **收集管理**：提交数据列表/详情、旗标与备注（单个与批量）、审核模式（先审后显）、回收站（还原/彻底删除）、回收站批量操作、CSV 导出（含公式注入防护、可选敏感字段脱敏）
- **跨表单数据聚合页**：全部表单的提交汇总一处，按表单/关键词/日期/状态筛选，跨表单批量标旗/备注/审核与聚合导出
- **统计分析**：单表单独立统计页——提交趋势、设备占比、选项分布、高频值排行
- **协作**：表单可绑定协作成员（数据范围 all/own、可否自建渠道、可否导出逐项授权），成员数据服务端强制隔离
- **渠道**：每表单多条分发渠道码，支持归属成员与**定时上下线**（生效时段外渠道码自动失效）
- **通知**：新提交 Webhook（钉钉/企业微信/飞书/自定义 JSON）、邮件通知、每日数据汇总邮件、桌面通知

### 页面（内容发布）

- 富文本编辑器（wangEditor v5）+ HTML 源码双视图
- 页面正文可**内嵌表单**（`{{form:分享码}}`，访客在页面里直接填写提交）、内嵌另一页面、外部链接按钮
- 表单侧联动：表单下方可挂关联入口按钮，提交成功后可自动跳转到指定页面或外链
- **四套展示模板**：纯净（默认）/ 卡片 / 优雅等，主题色可配，支持 SEO 设置与访问密码
- 页面浏览量统计（同会话去重）

### 引流中心（私域获客）

对标商业引流工具的核心玩法，一个二维码长期不变、内容随时可换：

- **活码系统**：上传多张二维码图片（群码/客服码），扫码后按策略分发；单张图设「扫码上限」，达到后自动切换下一张（**群满自动换群**），全部满员展示自定义满员提示
- **分发策略**：顺序轮询 / 随机分配 / **并流多码齐推**（适合多群同时推广，访客任选一张识别）；每个条目可再叠加**权重、设备（iOS/安卓/电脑）、生效时段（支持跨零点）**三重规则做精准分流，规则全部不命中时自动回退
- **短链**：长链接一键转短链；一个短码背后可配**多条目标链接轮询**（多域名轮换，降低单域名被限制的风险）；可选**中转引导页**，微信/抖音等封闭环境提示「右上角浏览器打开」
- **统计**：扫码/点击量、30 日趋势、条目分发占比、设备占比、命中明细；活码还统计**长按识别次数**（比扫码量更接近真实转化）
- **落地页**：手机优先的官方风格卡片，标题与引导文案可自定义；发布域名可选域名池（落地域名/备用域名策略）

### 数据与合规（0.0.3 新增）

- **数据保留策略**：按天数自动清理过期提交（含回收站），满足数据最小化要求
- **手动清理**：过期提交 / 回收站 / 孤儿附件三类范围独立勾选、天数各自设定，确认后立即执行并记录操作日志
- **每日汇总邮件**：每天自动发送昨日数据摘要
- 清理任务支持宝塔计划任务每日执行（无人登录也照常运行）

### 通用

- 多用户：管理员 + 成员两种角色，成员仅能管理自己创建的表单、页面与推广位（服务端强制数据隔离）
- 数据概览：提交量四维卡片（总/月/周/日带环比）、资源统计、热门表单/页面/推广位、最新提交
- 顶栏通知（新提交/待审核）、操作日志与 API 报文日志（可脱敏、可设保留期）、附件管理（本地/腾讯 COS/阿里 OSS/七牛，支持批量删除）
- AI 助理：表单设计器对话式生成表单结构；页面编辑器对话式生成页面内容（复用 OpenAI 兼容接口配置，输出统一安全过滤）
- 白标：系统名、Logo、登录页欢迎语、页脚、备案号可自定义

## 安全设计

| 维度 | 实现 |
|---|---|
| 认证 | bcrypt 密码、登录双维度（IP+账号）限频、登录后会话 ID 轮换（防会话固定）、会话 Cookie HttpOnly + SameSite |
| CSRF | 全局 Token 校验（恒时比较）+ Origin/Referer 同源校验，仅公开接口按白名单豁免 |
| XSS | 所有页面内容入库前 + 输出前双重消毒（白名单标签、剔除 script/事件属性/危险协议），AI 生成内容同样过滤 |
| SQL 注入 | 全参数化绑定，动态字段走白名单校验 |
| SSRF | Webhook / AI 接口 / SMTP / 对象存储端点统一协议白名单 + 内网/回环/云元数据网段拦截；活码/短链的跳转目标同样协议白名单 + 拒内网 |
| 越权 | 所有管理接口强制登录，敏感接口双重管理员校验，数据访问强制归属过滤 |
| 敏感数据 | 云存储/短信/邮件/AI 密钥 AES-256-GCM 加密落库，接口仅回显掩码（只写不读），数据库凭据与主密钥独立文件存储（不入包不入库） |
| 上传 | 扩展名白名单 + finfo 内容校验 + 大小/配额限制，随机文件名防穿越 |
| 日志 | 控制字符清洗（防伪造/终端注入）、敏感字段脱敏、按保留期自动清理 |
| 开放重定向 | 引流跳转目标只认后台配置值，不接收 URL 参数覆盖 |

## 快速开始（宝塔）

1. 上传发布包解压到站点，运行目录设为 `/public`
2. 按 `scripts/nginx-site.conf` 配置敏感目录拦截（默认放行 /install，安装后再关闭入口）
3. 访问 `/install` 完成安装（自动建表、生成配置与加密主密钥）
4. 安装完成后：`rm -rf install/ && chmod 555 config/`，创建 `.env`（`APP_DEBUG=false`，HTTPS 下 `COOKIE_SECURE=true`，建议设置 `SECRET_KEY`）
5. 登录 `/admin` 开始使用
6. （推荐）宝塔计划任务每日执行 `php 站点目录/think cleanup:run`

详见 `scripts/宝塔部署说明.txt`。

## 目录结构（简要）

```
app/               后端（controller 接口层 / logic 业务层 / middleware 中间件 / command 命令行）
config/            框架与应用配置（db_local.php、secret_key.php 由安装器生成，不入库）
public/            Web 根：static/fill 与 static/page 访客端、static/vendor 前端库、上传目录
                   （public/admin 管理端构建产物由 admin-src 构建生成）
install/           安装向导（安装完成后必须删除）
route/             路由定义
scripts/           打包脚本、Nginx 配置样例、增量升级 SQL、部署说明
docs/              系统介绍与产品介绍
admin-src/         管理端 Vue 源码
runtime/           框架缓存/日志/会话（需写权限，禁止 Web 直访）
```
