  OwnForm 自建表单收集系统 · 宝塔部署说明
  版本: 0.0.2
════════════════════════════════════════════════

【环境要求】
· 宝塔面板（Nginx + PHP 8.0 及以上）
· MySQL 5.7 / 8.0
· PHP 扩展需启用：pdo_mysql、mbstring、gd、fileinfo、curl

【部署步骤】
1. 宝塔新建站点（域名自定），PHP 版本选择 8.0 及以上，数据库选择 MySQL
2. 上传部署包到站点根目录并解压
   （可将 ownform 内的文件移动到站点根，或保持子目录并在站点设置中调整运行目录）

3. 站点设置：
   a. 【网站目录】运行目录选择 /public，保存
      ★ 必须指向 public。若指向项目根，runtime/ 与 config/ 将可被直接下载，
        攻击者能拿到会话文件（直接劫持管理员登录）与数据库凭据。
   b. 【伪静态】选择 thinkphp 模板，保存
   c. 【PHP 版本】确认 8.0+

4. 浏览器访问 http://你的域名/install 进入安装向导：
   a. 环境检测全部通过后，填写 MySQL 信息（地址/库名/账号/密码，库名不存在会自动创建）
   b. 设置管理员账号与密码（至少 6 位）
   c. 安装完成会自动生成 config/db_local.php 与 config/secret_key.php

5. ★ 安装完成后必须执行（不可跳过）：
   rm -rf install/                      # 删除安装器，杜绝重装接管风险
   chmod 555 config/                    # 配置目录改为只读
   chown -R www:www config/ runtime/ public/storage/

6. Nginx 敏感目录拦截（Apache 用户可跳过，项目已内置 .htaccess）：
   把 scripts/nginx-site.conf 里的 location 段粘贴到站点 server{} 内并重载 Nginx
   （该片段不含 location /，与步骤 3.b 的伪静态 thinkphp 模板不会重复冲突；
     默认放行 /install，安装完成后可按其第 4 段注释关闭安装器入口）

7. 创建 .env 文件（生产环境）：
   cp .example.env .env
   然后务必修改：
     APP_DEBUG = false        # 开启会把 SQL、服务器路径回显给访问者
     COOKIE_SECURE = true     # 启用 HTTPS 后必须为 true
     SECRET_KEY = <随机长字符串>  # 敏感配置加密主密钥（安装向导已生成
                                # config/secret_key.php 时可留空，二选一）
   生成随机密钥：head -c 32 /dev/urandom | base64

8. 建议启用 HTTPS（宝塔「SSL」→ Let's Encrypt），开启强制 HTTPS。
   未启用 HTTPS 时不要设置 COOKIE_SECURE = true，否则无法登录。

9. 使用 http://你的域名/admin 进入管理后台登录

【授权激活（系统提供方阅读）】
本系统为商业授权版本：安装与在线更新均依赖「授权与更新中心」
（独立部署在提供方服务器，见 ownform-授权中心.zip 内说明）。
客户在安装向导第 2 步填写授权服务器地址与授权码，验证通过才能完成安装。
系统每日自动心跳校验；服务器不可达时有 30 天宽限期，宽限期内可用
离线激活码完成校验；超期进入只读模式（后台可查看，前台暂停收集），
完成激活即恢复。换域名/换机请联系提供方解绑。

【计划任务（每日自动清理 + 汇总邮件，建议配置）】
0.0.3 起系统支持数据保留策略与每日数据汇总邮件（系统设置 → 数据与合规 / 通知）。
不挂计划任务也能用：每天首个打开「数据概览」的请求会自动触发一次；
但挂上计划任务更可靠——无人登录的日子也照常清理、照常发汇总邮件。

宝塔配置步骤：
1. 宝塔面板 → 计划任务 → 添加任务
2. 任务类型：Shell 脚本
3. 任务名称：OwnForm 每日清理
4. 执行周期：每天（建议凌晨 4 点左右，避开业务高峰）
5. 脚本内容（按实际站点目录与 PHP 版本替换）：

   /www/server/php/80/bin/php /www/wwwroot/你的站点目录/think cleanup:run >> /www/wwwroot/你的站点目录/runtime/cleanup.log 2>&1

说明：
· /www/server/php/80 是宝塔 PHP 8.0 的路径，按站点实际使用的版本调整
  （8.1 为 php/81，8.2 为 php/82，以此类推）
· 手动验证：SSH 到服务器直接执行上面命令，输出"清理过期提交：N 条 / done"即正常
· 加 --force 参数可忽略"每日一次"节流强制执行（调试用）：
  php 站点目录/think cleanup:run --force
· 该任务同时负责：过期提交清理（含回收站）、孤儿附件清理、每日汇总邮件发送；
  未开启保留期（0 = 永久）时只清理孤儿附件，开启了汇总邮件则照常发送

【自定义页面模块】
· 管理后台 → 页面管理，可创建 /p/{slug} 形式的公开页面
· 支持富文本、Markdown、HTML 源码三种编辑模式
· 可在页面正文中插入内嵌表单、内嵌页面、外链按钮：
  {{form:表单分享码}}   {{page:页面分享码}}   {{url:https://...}}
· 页面内容由后端统一消毒（后端 app/logic/HtmlSanitizer.php），
  script / iframe / on* 事件 / javascript: 协议均会被移除，
  前端预览也做了同等处理

【目录权限】
需要网站用户（www）可写：
· runtime/          （框架缓存与日志）
· public/storage/   （上传文件，本地存储模式）

不需要可写：
· config/           （仅安装时写入，安装后应设为只读）

【CDN / 反向代理部署】
系统设置 → 客户端 IP：
· 直连部署：客户端 IP 头 选 REMOTE_ADDR（默认，不要改）
· CDN/反代：选 X-Forwarded-For，并必须填写「可信代理」为你的代理 IP
  （支持单个 IP、CIDR 如 10.0.0.0/8、区间如 192.168.1.1-192.168.1.20）
  未配置可信代理时系统会拒绝采信任何转发头，此时限频会退化为按代理 IP 计算。

【常用配置】
· 品牌白标 / 云存储 / 短信 / 极验 / AI 助理 / 提交通知：
  管理后台 → 系统设置
  （提交 Webhook 与邮件通知受「启用通知」总开关控制，
    「发送测试」不受该开关限制。
    密钥类字段保存后显示为掩码，如 sk-a****xyz。
    留空或保持掩码即表示不修改；要更换请直接输入新值。）
· 修改密码：右上角头像 → 修改密码
· 提交报文排查：系统设置 → 日志调试 开启后，
  在 日志管理 → 操作日志（模块「接口报文」）中查看接口请求/响应

【安全提醒】
· 安装完成后务必删除 install/ 目录并删除 install/installed.lock
· 生产环境 APP_DEBUG 必须为 false
· 站点必须启用 HTTPS
· 数据库请使用独立低权限账号，不要使用 root
· config/db_local.php 与 config/secret_key.php 含敏感凭据，
  已在 .gitignore 中排除，切勿提交到版本库
· 出站地址（Webhook / AI 接口 / SMTP / 对象存储）已禁止指向内网与
  云元数据地址，如确有内网需求请勿在系统设置中配置
